# Data Description

All data is **synthetic**, generated by `src/data_generator.py` (numpy, seed 42). Files are saved to `data/`.

## Table `users.csv`

One row per visitor included in the experiment (5000 rows).

| Column | Type | Meaning | Values / range |
|--------|------|---------|----------------|
| `user_id` | integer | Unique visitor identifier | 100001 to 105000 |
| `group` | string | Experiment arm the visitor was randomly assigned to | `control`, `variant` |
| `visit_date` | string (date, YYYY-MM-DD) | Date of the visit to the landing page | 2025-03-03 to 2025-03-16 |
| `device` | string | Device type used | `mobile`, `desktop`, `tablet` |
| `traffic_source` | string | Acquisition channel | `organic`, `paid_search`, `social`, `email`, `direct` |
| `country` | string | Visitor country code | `US`, `UK`, `DE`, `FR`, `CA` |
| `is_returning` | integer (0/1) | 1 if the visitor has visited before | 0, 1 |
| `page_views` | integer | Number of pages viewed in the session | 1 to 15 |
| `time_on_page_sec` | float | Time spent on the landing page, in seconds | 5.0 to 600.0 |
| `converted` | integer (0/1) | 1 if the visitor placed an order | 0, 1 |

## Table `orders.csv`

One row per order. Only visitors with `converted = 1` have an order, and each has exactly one.

| Column | Type | Meaning | Values / range |
|--------|------|---------|----------------|
| `order_id` | integer | Unique order identifier | Starts at 500001, consecutive |
| `user_id` | integer | Buyer, foreign key to `users.user_id` | 100001 to 105000 |
| `order_date` | string (date, YYYY-MM-DD) | Date the order was placed (0 to 2 days after the visit) | 2025-03-03 to 2025-03-18 |
| `items` | integer | Number of items in the order | 1 to 5 |
| `order_value` | float | Order value in currency units (USD-like) | 10.00 to 500.00 |

## Relationships

- `orders.user_id` references `users.user_id` (many-to-one in general, one-to-one in this dataset).
- `users.converted = 1` if and only if the visitor has a row in `orders`.
