# Data Description

All data is **synthetic**, generated by `src/data_generator.py` with a fixed random seed (42). Value ranges below describe how the data is constructed (clipping bounds and generator parameters), not statistics from a real source.

## Table `products` (`data/products.csv`)

One row per product: 60 rows (5 categories x 12 products).

| Column | Type | Meaning | Value range |
|--------|------|---------|-------------|
| `product_id` | integer | Unique product identifier | 1 to 60 |
| `category` | string | Product category | Beverages, Snacks, Personal Care, Household, Dairy |
| `brand_tier` | string | Brand positioning of the product | Budget, Mainstream, Premium |
| `base_price` | float | Regular reference price of the product (currency units) | clipped to 1.50 – 15.00 |

## Table `weekly_sales` (`data/weekly_sales.csv`)

One row per product per week: 60 products x 52 weeks = 3120 rows.

| Column | Type | Meaning | Value range |
|--------|------|---------|-------------|
| `product_id` | integer | Foreign key to `products.product_id` | 1 to 60 |
| `week_start` | date (YYYY-MM-DD) | Monday that starts the week | 52 consecutive weeks starting 2024-01-01 |
| `week_of_year` | integer | Week number within the year | 1 to 52 |
| `price` | float | Actual selling price in that week, after any promotional discount | positive; typically near `base_price`, up to about 30% lower in promo weeks |
| `competitor_price` | float | Average competitor price for a comparable product | positive; typically within about ±25% of `base_price` |
| `is_promo` | integer (0/1) | 1 if the product was on promotion that week | 0 or 1 (about 15% of rows by design) |
| `is_holiday_week` | integer (0/1) | 1 for holiday-season weeks (weeks 47, 48, 51, 52) | 0 or 1 |
| `units_sold` | integer | Units sold in the week | non-negative integer |
| `revenue` | float | `price * units_sold` | non-negative |

## Notes on how demand is generated

- Demand follows a constant-elasticity (log-log) model with a different true elasticity for each category (plus a small product-level deviation). The true values live only in the generator code and are not saved in the CSV files.
- Demand also depends on competitor price (cross-price effect), a smooth yearly seasonal pattern, a holiday uplift and an extra promotion lift.
- Units are drawn from a Poisson distribution around the expected demand.
- Promotions cut the price by 10–30%, so price and `is_promo` are correlated; models should control for `is_promo`.
