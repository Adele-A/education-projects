# Data Description

All data is **synthetic**, generated by `src/data_generator.py` with random seed 42. The snapshot date is 2026-10-31. Files are saved in `data/`.

## Table `members.csv`

One row per member (3000 rows).

| Column | Type | Meaning | Value range |
|--------|------|---------|-------------|
| member_id | string | Unique member identifier | `M00001` to `M03000` |
| signup_date | date (YYYY-MM-DD) | Date the member joined | 2023-01-01 to 2026-08-31 |
| age | integer | Age in years | 16 to 70 |
| gender | string | Gender | Female, Male, Other |
| city | string | City of the member's home gym | Springfield, Riverton, Lakeside, Hillcrest, Brookfield |
| initial_plan | string | Plan chosen at sign-up | Basic, Standard, Premium |
| current_plan | string | Plan at the end of membership or at the snapshot (after any upgrade) | Basic, Standard, Premium |
| monthly_fee | float | Monthly fee of the current plan | 29.99, 49.99 or 79.99 |
| contract_type | string | Contract type | Month-to-month, Annual |
| payment_method | string | Payment method | Card, Direct debit, Cash |
| distance_to_gym_km | float | Distance from home to the gym in km | 0.1 to 30.0 |
| has_personal_trainer | integer (0/1) | 1 if the member uses a personal trainer | 0 or 1 |
| uses_group_classes | integer (0/1) | 1 if the member attends group classes | 0 or 1 |
| avg_visits_per_week | float | Average gym visits per week over the last 90 days of membership | 0.0 to 7.0 |
| days_since_last_visit | integer | Days since the last visit | 0 to 120 |
| tenure_months | float | Months from sign-up to churn date (churned) or to the snapshot (active) | about 1.5 to 46 |
| is_churned | integer (0/1) | 1 if the member cancelled before the snapshot (target for churn model) | 0 or 1 |
| churn_date | date (YYYY-MM-DD) | Cancellation date; empty for active members | 45 days after sign-up up to 2026-10-31 |

## Table `upgrades.csv`

One row per plan upgrade event. Each member has at most one upgrade.

| Column | Type | Meaning | Value range |
|--------|------|---------|-------------|
| upgrade_id | string | Unique upgrade identifier | `U00001`, `U00002`, ... |
| member_id | string | Member who upgraded (links to `members.member_id`) | existing member IDs |
| upgrade_date | date (YYYY-MM-DD) | Date of the upgrade | at least 60 days after sign-up, before the end of membership |
| from_plan | string | Plan before the upgrade | Basic, Standard |
| to_plan | string | Plan after the upgrade | Standard, Premium |
| monthly_fee_before | float | Monthly fee before the upgrade | 29.99 or 49.99 |
| monthly_fee_after | float | Monthly fee after the upgrade | 49.99 or 79.99 |

## Notes

- Members on the Premium plan at sign-up cannot upgrade.
- Only members with at least 90 days of membership are eligible for an upgrade.
- Churn probability in the generator depends on visit frequency, days since last visit, distance, plan, contract type, personal trainer and group classes.
