# Loan Portfolio Analytics

## Business question
How healthy is our consumer and small-business loan book? Where is credit risk concentrated, and how do newer cohorts of loans compare with older ones as they age?

## Goal
Build the data foundation for a portfolio dashboard with these KPIs:
- **Delinquency buckets**: share of outstanding balance that is current, 1-29, 30-59, 60-89 and 90+ days past due.
- **Vintage curves**: delinquency and charge-off rates by origination month, plotted against months on book.
- **Exposure by segment**: outstanding balance split by credit segment, product type, region and risk grade.

## Plan
1. **Data generation** (this step): produce a synthetic loan book with `src/data_generator.py`.
2. **EDA**: check data quality, distributions, and the balance and delinquency mix.
3. **Analysis**: compute the delinquency bucket mix, roll rates, vintage curves and exposure tables.
4. **SQL**: write the portfolio KPI queries (bucket mix, vintage, exposure) in `sql/`.
5. **Tests**: add `pytest` checks for data integrity and KPI logic in `tests/`.

## Dataset (synthetic)
All data is **synthetic**. It is generated by `src/data_generator.py` with numpy and a fixed seed (42). It does not describe real customers or a real lender. Three tables are saved to `data/`:

| Table | Grain | Description |
|---|---|---|
| `customers.csv` | one row per customer | demographics, income, credit score, credit segment |
| `loans.csv` | one row per loan | origination date, product, principal, rate, term, risk grade |
| `loan_snapshots.csv` | one row per loan per month-end | balance, delinquency bucket, loan status |

The monthly snapshots come from a simple Markov-chain simulation of delinquency states. Transition probabilities depend on the loan's risk grade. The snapshot data ends at the as-of date 2025-12-31.

See `data_description.md` for every column.

## How to run
From the project root:

```bash
pip install -r requirements.txt
python src/data_generator.py
```

The CSV files are written to `data/`.
