# Data Description

All data is **synthetic**, generated by `src/data_generator.py` (numpy, seed 42). It does not represent real suppliers or shipments. Files are saved in `data/`.

Ranges below are the valid ranges enforced by the generator (clipping or sampling bounds), not observed statistics.

## Table `suppliers.csv` (60 rows, one row per supplier)

| Column | Type | Meaning | Value range |
|---|---|---|---|
| supplier_id | string | Unique supplier key | `S001` to `S060` |
| supplier_name | string | Supplier display name | `Supplier 001` to `Supplier 060` |
| country | string | Supplier country | USA, Mexico, Germany, Poland, Turkey, China, Vietnam, India |
| region | string | Geographic region of the country | North America, Europe, Asia |
| category | string | Main product category supplied | Electronics, Raw Materials, Packaging, Components, MRO |
| transport_mode | string | Usual transport mode used by the supplier | road, rail, sea, air |
| reliability_tier | string | Hidden-quality tier driving lead time noise and disruptions (A = most reliable, C = least) | A, B, C |
| contract_lead_time_days | integer | Contractual lead time in days | 3 to 45 |
| price_index | float | Supplier price level relative to the category base price | 0.7 to 1.4 |

## Table `purchase_orders.csv` (5000 rows, one row per purchase order)

| Column | Type | Meaning | Value range |
|---|---|---|---|
| po_id | string | Unique purchase order key, sequential by order date | `PO-000001` to `PO-005000` |
| supplier_id | string | Foreign key to `suppliers.supplier_id` | `S001` to `S060` |
| order_date | date (YYYY-MM-DD) | Date the order was placed | 2023-01-01 to 2025-06-30 |
| promised_date | date (YYYY-MM-DD) | Delivery date promised by the supplier (order date + promised lead time) | after `order_date` |
| delivery_date | date (YYYY-MM-DD) | Actual delivery date (order date + actual lead time) | after `order_date` |
| promised_lead_time_days | integer | Promised lead time in days | at least 1 |
| actual_lead_time_days | integer | Actual lead time in days | 1 to 150 |
| delay_days | integer | `delivery_date - promised_date` in days; negative means early | can be negative, zero or positive |
| on_time | integer (0/1) | 1 if `delay_days <= 0`, otherwise 0 | 0 or 1 |
| order_qty | integer | Ordered quantity in units | 10 to 5000 |
| unit_price | float | Price per unit in USD | positive |
| is_expedited | integer (0/1) | 1 if the order was expedited (shorter lead time, 10% price premium) | 0 or 1 |
| order_value | float | `order_qty * unit_price` in USD | positive |

## Relationships

- `purchase_orders.supplier_id` references `suppliers.supplier_id` (many orders per supplier).
- All orders are already delivered, so no delivery dates are missing.
