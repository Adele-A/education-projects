# Online Course Engagement

Learner engagement, completion funnel and dropout prediction on a **synthetic** online-learning dataset.

> **Note:** all data in this project is synthetic. It is generated by `src/data_generator.py` with a fixed random seed (42). It does not describe real learners, courses or platforms.

## Business question

Where in the course journey do learners lose interest, and which early engagement signals tell us that a learner is likely to drop out, early enough for the team to intervene?

## Goal

1. Describe how learners progress through a course (enrolled, started, 25%, 50%, 75%, completed) and where the largest drop-offs happen.
2. Compare engagement and completion across learner segments (device, acquisition channel, prior experience, country) and course types (category, difficulty, free vs. paid).
3. Build a model that predicts dropout from the information available after the first week of a course.

## Plan of the work

1. **Data generation** (`src/data_generator.py`): create three related synthetic tables (learners, courses, enrollments).
2. **EDA**: data quality checks, distributions, missing values, completion funnel, segment comparisons.
3. **Analysis / model**: statistical tests for segment differences and a dropout classifier (for example logistic regression and gradient boosting) evaluated with a hold-out set and cross-validation.
4. **SQL**: queries for the funnel, segment completion rates and course-level engagement metrics.
5. **Tests**: pytest checks for data integrity (keys, ranges, consistency between columns) and for the analysis helper functions.

## Dataset (synthetic)

Three CSV tables are written to `data/`:

| Table | Rows | Description |
|-------|------|-------------|
| `learners.csv` | 2000 | One row per learner: signup date and profile attributes |
| `courses.csv` | 20 | One row per course: category, difficulty, length, price |
| `enrollments.csv` | 4500 | One row per learner-course enrollment: engagement metrics and outcome |

The full column-level description is in [data_description.md](data_description.md).
