# Data Description

All data is **synthetic**, generated by `src/data_generator.py` with a fixed seed (42). Ranges below are the limits enforced by the generator's design.

## Table `data/customers.csv`

One row per customer (1000 rows).

| Column | Type | Meaning | Value range |
|---|---|---|---|
| `customer_id` | string | Unique customer identifier | `C0001` to `C1000` |
| `signup_date` | date (YYYY-MM-DD) | Date the customer registered | 2023-01-01 to 2025-09-30 |
| `country` | string (category) | Customer's country | United States, United Kingdom, Germany, France, Canada, Spain |
| `age` | integer | Customer age in years | 18 to 75 |
| `acquisition_channel` | string (category) | Channel through which the customer was acquired | organic_search, paid_search, social_media, email, referral |
| `newsletter_subscriber` | integer (binary) | 1 if subscribed to the newsletter, otherwise 0 | 0 or 1 |

## Table `data/orders.csv`

One row per order (at most 5000 rows). Every customer has at least one order.

| Column | Type | Meaning | Value range |
|---|---|---|---|
| `order_id` | string | Unique order identifier, numbered in date order | `O000001` onward |
| `customer_id` | string | Customer who placed the order (links to `customers.customer_id`) | `C0001` to `C1000` |
| `order_date` | date (YYYY-MM-DD) | Date of the order; never earlier than the customer's `signup_date` | up to 2025-12-31 |
| `order_value` | float | Total order amount in currency units | 5.00 to 2000.00 |
| `items_count` | integer | Number of items in the order | 1 or more (Poisson-based, typically 1 to 6) |
| `payment_method` | string (category) | Payment method used | credit_card, paypal, debit_card, gift_card |
| `discount_used` | integer (binary) | 1 if a discount code was applied, otherwise 0 | 0 or 1 |

## Notes

- The generator draws customers from four hidden behavioral groups (high-frequency, regular, occasional, lapsed). The group label is not saved, so segments must be recovered from behavior.
- The analysis snapshot date is expected to be shortly after 2025-12-31 (the end of the data).
