# Data description

All tables are **synthetic**, generated by `src/data_generator.py` (numpy, seed 42). Files are saved in `data/`. Value ranges below come from the generator's design (parameters and clipping); actual observed statistics should be checked in the EDA step.

Period: 30 days, hourly, from 2025-01-01 00:00 to 2025-01-30 23:00 (720 timestamps).

## households.csv (6 rows)

| Column | Type | Meaning | Value range |
|---|---|---|---|
| household_id | string | Unique household identifier | `H001` to `H006` |
| dwelling_type | string | Type of dwelling | `apartment`, `house` |
| n_residents | integer | Number of people living in the household | 1 to 5 |
| floor_area_m2 | integer | Floor area in square metres | apartments 35 to 90, houses 90 to 180 |
| has_electric_heating | integer (0/1) | 1 if the household heats with electricity | 0 or 1 (three households each) |

## weather_hourly.csv (720 rows)

| Column | Type | Meaning | Value range |
|---|---|---|---|
| timestamp | string (`YYYY-MM-DD HH:MM:SS`) | Hour of the observation | 2025-01-01 00:00:00 to 2025-01-30 23:00:00 |
| temperature_c | float | Outdoor temperature in degrees Celsius, 1 decimal | Not hard-limited; centred around 2 °C with a daily cycle and multi-day drift |

## energy_hourly.csv (4320 rows = 6 households x 720 hours)

| Column | Type | Meaning | Value range |
|---|---|---|---|
| household_id | string | Household identifier, links to `households.household_id` | `H001` to `H006` |
| timestamp | string (`YYYY-MM-DD HH:MM:SS`) | Hour of the measurement, links to `weather_hourly.timestamp` | 2025-01-01 00:00:00 to 2025-01-30 23:00:00 |
| kwh | float | Electricity consumed in that hour, in kWh, 3 decimals | 0.05 to 8.0 (clipped) |

Each (`household_id`, `timestamp`) pair appears exactly once.
