# Data Description

All data is **synthetic**, generated by `src/data_generator.py` (numpy, seed 42). It does not represent any real hotel or guest.

Files are saved to `data/`.

## Table `guests.csv` (3,500 rows)

One row per guest.

| Column | Type | Meaning | Value range |
|---|---|---|---|
| `guest_id` | string | Unique guest identifier | `G00001` to `G03500` |
| `country` | string (category) | Guest's country of residence | USA, UK, Germany, France, Spain, Italy, Netherlands, Other |
| `age_group` | string (category) | Age bracket of the guest | 18-29, 30-44, 45-59, 60+ |
| `previous_stays` | integer | Number of completed stays before the observed period | 0 to 8 |
| `previous_cancellations` | integer | Number of earlier bookings the guest canceled | 0 to `previous_stays` |

## Table `bookings.csv` (5,000 rows)

One row per booking. `guest_id` links to `guests.csv` (many bookings can belong to one guest).

| Column | Type | Meaning | Value range |
|---|---|---|---|
| `booking_id` | string | Unique booking identifier | `B00001` to `B05000` |
| `guest_id` | string | Guest who made the booking (foreign key to `guests.guest_id`) | `G00001` to `G03500` |
| `hotel_type` | string (category) | Type of hotel | City Hotel, Resort Hotel |
| `arrival_date` | string (date, `YYYY-MM-DD`) | Planned arrival date | 2024-01-01 to 2025-12-31 |
| `arrival_month` | integer | Month of the arrival date | 1 to 12 |
| `lead_time_days` | integer | Days between booking and arrival | 0 to 450 |
| `stay_nights_weekend` | integer | Booked weekend nights | 0 to 6 |
| `stay_nights_week` | integer | Booked weekday nights (at least 1 night in total per booking) | 0 to 14 |
| `adults` | integer | Number of adults | 1 to 3 |
| `children` | integer | Number of children | 0 to 2 |
| `meal_plan` | string (category) | Booked meal plan | Bed & Breakfast, Half Board, Full Board, Self Catering |
| `market_segment` | string (category) | Sales channel / customer segment | Online TA, Offline TA, Direct, Corporate, Groups |
| `deposit_type` | string (category) | Deposit policy of the booking | No Deposit, Non Refundable, Refundable |
| `room_type` | string (category) | Reserved room category | A, B, C, D |
| `adr` | float | Average daily rate (currency units per night) | 30.00 to 400.00 |
| `special_requests` | integer | Number of special requests made | 0 to 4 |
| `parking_spaces` | integer | 1 if a parking space was requested, otherwise 0 | 0 or 1 |
| `booking_changes` | integer | Number of changes made to the booking | 0 to 5 |
| `is_canceled` | integer | **Target.** 1 if the booking was canceled, 0 otherwise | 0 or 1 |

## Notes

- `is_canceled` is drawn from a hand-designed logistic model, so relationships between features and cancellations reflect that design rather than real guest behavior.
- The `Non Refundable` deposit type is deliberately given a strong positive effect on cancellation, which mimics a quirk seen in some real hotel data.
