# Data Description

All data is **synthetic**, generated by `src/data_generator.py` (numpy, seed 42). Files are saved to `data/`. Exact observed value ranges are examined later in the EDA step; the ranges below follow from the generator's design.

## categories.csv

One row per medicine category (8 rows).

| Column | Type | Meaning | Value range |
|--------|------|---------|-------------|
| category | string | Medicine category name (unique key) | cold_and_flu, allergy, vitamins, sun_care, digestive, pain_relief, first_aid, cardio_chronic |
| seasonality_pattern | string | Short description of the designed seasonal pattern | e.g. "winter peak", "spring peak", "summer peak", "almost flat" |
| base_weekly_units | integer | Baseline weekly demand before trend, seasonality and promotions | 600 to 1800 |
| base_unit_price | float | Baseline price per unit in the first year, before inflation and discounts | 4.0 to 18.0 |

## weekly_sales.csv

One row per week and category (260 weeks x 8 categories = 2080 rows). Weeks start on Monday, from 2019-01-07 for 260 consecutive weeks.

| Column | Type | Meaning | Value range |
|--------|------|---------|-------------|
| week_start | date (YYYY-MM-DD) | Monday of the sales week | 2019-01-07 to 2023-12-25 |
| category | string | Medicine category, foreign key to `categories.category` | the 8 categories above |
| units_sold | integer | Units sold in the week (Poisson draw around the expected demand) | non-negative integer |
| unit_price | float | Average selling price per unit in the week, after any promotion discount | positive; base price grows about 3% per year, 10% lower in promo weeks |
| promo_flag | integer | 1 if a promotion ran in that week for that category, otherwise 0 | 0 or 1 (about 10% of weeks) |
| revenue | float | `units_sold * unit_price`, rounded to 2 decimals | non-negative |
| avg_temp_c | float | Average air temperature of the week in degrees Celsius (same value for all categories in a week) | clipped to -10.0 to 38.0 |

There are no intentionally missing values in this version of the data.
