# Data description

All data is **synthetic**, generated by `src/data_generator.py` (numpy, seed 42). Files are saved in `data/`. Ranges below describe how the generator is designed; exact summary statistics should be taken from the data itself during EDA.

## Table `stores.csv`

6 rows, one per store.

| Column | Type | Meaning | Value range |
|---|---|---|---|
| store_id | string | Unique store identifier | `S01` to `S06` |
| region | string | Sales region of the store | `North`, `South`, `East`, `West` |
| size_sqm | integer | Store floor area in square meters | 800 to 3000 |
| opened_year | integer | Year the store opened | 2005 to 2020 |

## Table `weekly_sales.csv`

One row per week, store and category: 156 weeks x 6 stores x 4 categories = 3744 rows.

| Column | Type | Meaning | Value range |
|---|---|---|---|
| week_start | date (YYYY-MM-DD) | Monday that starts the sales week | 2022-01-03 to 2024-12-23, weekly steps |
| store_id | string | Store identifier, links to `stores.store_id` | `S01` to `S06` |
| category | string | Product category | `Grocery`, `Electronics`, `Clothing`, `Garden` |
| units_sold | integer | Units sold in the week | Non-negative; level depends on category and store size (Electronics lowest, Grocery highest by design) |
| unit_price | float | Average selling price per unit | Positive; around the category base price (Grocery ~4.5, Electronics ~180, Clothing ~32, Garden ~18) with about -10% in promotion weeks |
| promo_flag | integer (0/1) | 1 if the row is a promotion week | 0 or 1 (about 12% of rows by design) |
| holiday_week | integer (0/1) | 1 if the week contains Christmas Eve/Day or Black Friday | 0 or 1 |
| revenue | float | `units_sold * unit_price`, rounded to 2 decimals | Non-negative |

## Generation logic (summary)

- Expected units = base level (category x store size) x growth trend (+3% per year) x yearly seasonality (category-specific) x holiday uplift x promotion uplift (+10% to +30%) x log-normal noise (sigma 0.06).
- Seasonal peaks by design: Garden in summer, Clothing in spring, Electronics and Grocery around December.
