# Data Description

All data is **synthetic**, generated by `src/data_generator.py` with a fixed random seed (42). It does not represent real people or loans.

Tables are saved in `data/` and linked by `customer_id` (one customer can have several loans; some customers have none).

## Table `customers.csv` (4000 rows)

| Column | Type | Meaning | Value range |
|--------|------|---------|-------------|
| `customer_id` | int | Unique customer identifier (primary key) | 1 to 4000 |
| `age` | int | Customer age in years | 18 to 75 |
| `annual_income` | float | Annual income in currency units | 15,000 to 250,000 |
| `employment_years` | float | Years of employment, never more than age minus 18 | 0 to 45 |
| `home_ownership` | str | Housing status | `RENT`, `MORTGAGE`, `OWN` |
| `region` | str | Region of residence | `North`, `South`, `East`, `West` |
| `credit_score` | int | Credit score at registration | 300 to 850 |
| `existing_debt` | float | Outstanding debt before the new loan | 0 to annual income |
| `num_credit_lines` | int | Number of open credit lines | 1 to 20 |

## Table `loans.csv` (5000 rows)

| Column | Type | Meaning | Value range |
|--------|------|---------|-------------|
| `loan_id` | int | Unique loan identifier (primary key), ordered by application date | 1 to 5000 |
| `customer_id` | int | Borrower (foreign key to `customers.customer_id`) | 1 to 4000 |
| `loan_amount` | float | Requested and granted principal | 500 to 40,000 |
| `term_months` | int | Loan term in months | 36 or 60 |
| `interest_rate` | float | Annual interest rate in percent; lower for stronger credit scores | 4 to 30 |
| `loan_purpose` | str | Purpose of the loan | `debt_consolidation`, `credit_card`, `home_improvement`, `car`, `small_business`, `medical`, `other` |
| `application_date` | str (YYYY-MM-DD) | Date of the application | 2022-01-01 to 2023-12-31 |
| `debt_to_income` | float | (existing_debt + loan_amount) / annual_income | 0 to 3 |
| `num_delinquencies_2y` | int | Number of delinquencies in the last 2 years | 0 to 10 |
| `default` | int | Target: 1 if the loan defaulted, 0 if repaid | 0 or 1 |

## Notes

- `default` is drawn from a logistic risk function of `credit_score`, `debt_to_income`, `num_delinquencies_2y`, `interest_rate`, `loan_purpose`, `term_months`, home ownership and employment length. Defaults are intended to be the minority class.
- The actual default rate is printed by `python src/data_generator.py` after generation.
