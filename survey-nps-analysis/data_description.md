# Data Description

All data is **synthetic**. It is generated by `src/data_generator.py` (numpy, seed 42) and does not represent real customers or real survey answers. Files are saved to `data/`.

## Table `customers.csv` (4000 rows)

One row per customer.

| Column | Type | Meaning | Value range |
|---|---|---|---|
| customer_id | integer | Unique customer identifier (primary key) | 1 to 4000 |
| segment | string | Customer segment | Consumer, Small Business, Enterprise |
| plan | string | Subscription plan | Basic, Standard, Premium |
| region | string | Customer region | North, South, East, West |
| acquisition_channel | string | Channel through which the customer was acquired | Online, Retail Store, Referral, Partner |
| signup_date | string (date, YYYY-MM-DD) | Approximate signup date, derived as 2025-12-31 minus tenure_months x 30 days | Dates before 2025-12-31 |
| tenure_months | integer | Months since signup | 1 to 72 |

## Table `survey_responses.csv` (3000 rows)

One row per survey response. Each surveyed customer answered once, so `customer_id` is unique in this table.

| Column | Type | Meaning | Value range |
|---|---|---|---|
| response_id | integer | Unique response identifier (primary key), numbered in order of survey date | 1 to 3000 |
| customer_id | integer | Foreign key to `customers.customer_id` | Subset of 1 to 4000 |
| survey_date | string (date, YYYY-MM-DD) | Date the survey was answered | 2025-01-01 to 2025-12-31 |
| nps_score | integer | Answer to "How likely are you to recommend us?" | 0 to 10 |
| nps_category | string | NPS bucket derived from the score: 0-6 Detractor, 7-8 Passive, 9-10 Promoter | Detractor, Passive, Promoter |
| comment | string | Optional free-text comment, consistent in tone with the category. Missing for roughly 30% of responses by design | Short English sentences; empty when missing |

## Relationships
- `survey_responses.customer_id` references `customers.customer_id` (many responses table rows to one customer, but exactly one response per customer in this dataset).
- Scores are generated from a latent satisfaction level that depends on segment, plan, region and tenure plus random noise, so differences between groups exist by design.
