# Data Description

All data is **synthetic**, generated by `src/data_generator.py` (numpy, seed 42). It does not represent a real website.

Funnel steps are nested: `purchased` ≤ `reached_checkout` ≤ `added_to_cart` ≤ `viewed_product`. Every row is a session, so the first funnel step (session start) is the total row count.

## data/sessions.csv (5000 rows)

| Column | Type | Meaning | Value range |
|--------|------|---------|-------------|
| session_id | int | Unique session identifier | 1 to 5000 |
| session_date | string (YYYY-MM-DD) | Date the session started; rows are ordered by date | 2025-01-01 to 2025-03-31 |
| traffic_source | string | Channel that brought the session | organic_search, paid_search, direct, social, email, referral |
| device | string | Device category | desktop, mobile, tablet |
| country | string | Visitor country code | US, UK, DE, FR, CA, AU |
| user_type | string | Whether the visitor is new or has visited before | new, returning |
| pages_viewed | int | Number of pages viewed in the session | 1 or more |
| session_duration_sec | int | Session length in seconds | 3 to 3600 |
| viewed_product | int (0/1) | 1 if the session viewed a product page | 0, 1 |
| added_to_cart | int (0/1) | 1 if an item was added to the cart | 0, 1 |
| reached_checkout | int (0/1) | 1 if the session started checkout | 0, 1 |
| purchased | int (0/1) | 1 if the session completed an order | 0, 1 |
| order_value | float | Order amount in USD; 0.0 when `purchased` = 0 | 0.0, or positive for purchases |

## data/traffic_sources.csv (6 rows)

| Column | Type | Meaning | Value range |
|--------|------|---------|-------------|
| traffic_source | string | Traffic source name (key that joins to `sessions.traffic_source`) | organic_search, paid_search, direct, social, email, referral |
| channel_type | string | Type of channel | paid, unpaid, owned |
| cost_per_session | float | Assumed average acquisition cost per session in USD | 0.00 to 1.20 |
