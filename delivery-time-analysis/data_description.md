# Data Description

All data is **synthetic**, generated by `src/data_generator.py` (numpy, seed 42). Files are saved in `data/`. Value ranges below are the bounds enforced by the generator. There are no missing values by design.

## Table `couriers.csv` (300 rows)

| Column | Type | Meaning | Value range |
|---|---|---|---|
| courier_id | int | Unique courier identifier (primary key) | 1 to 300 |
| vehicle_type | string | Courier's vehicle | `bike`, `scooter`, `car` |
| experience_months | int | Months of courier experience | 1 to 120 |
| avg_rating | float | Average customer rating | 3.0 to 5.0 |

## Table `orders.csv` (5000 rows)

| Column | Type | Meaning | Value range |
|---|---|---|---|
| order_id | int | Unique order identifier (primary key), ordered by time | 1 to 5000 |
| courier_id | int | Courier who delivered the order (foreign key to `couriers.courier_id`) | 1 to 300 |
| order_datetime | datetime | Date and time the order was placed | 90 days starting 2025-01-01 |
| is_peak_hour | int | 1 if the order was placed at a peak hour (12:00-13:59 or 18:00-20:59), else 0 | 0 or 1 |
| distance_km | float | Distance from restaurant to customer, in km | 0.3 to 15.0 |
| weather | string | Weather condition at the time of the order | `clear`, `cloudy`, `rain`, `snow` |
| courier_active_orders | int | Number of orders the courier is handling, including this one (courier load) | 1 to 6 |
| prep_time_min | float | Restaurant preparation time, in minutes | 3.0 to 35.0 |
| delivery_time_min | float | Total time from order placement to delivery, in minutes (target variable) | 8.0 to 120.0 |

## Relationships
- `orders.courier_id` references `couriers.courier_id` (many orders per courier).
- `delivery_time_min` is built from preparation time, travel time (distance, vehicle speed, weather, courier experience), a penalty for courier load and random noise. These effects are assumptions of the generator, not real-world measurements.
