# Data Description

All data is **synthetic**, generated by `src/data_generator.py` with a fixed seed (42). It does not represent real flights or airlines. Files are saved in `data/`.

## airports.csv (12 rows)
One row per airport.

| Column | Type | Meaning | Value range |
|---|---|---|---|
| airport_code | string | Three-letter airport code (primary key) | 12 unique codes: ATL, ORD, DFW, DEN, LAX, SFO, SEA, JFK, BOS, MIA, PHX, MSP |
| city | string | City served by the airport | 12 unique city names |
| region | string | Region of the country | South, Midwest, West, Northeast |
| latitude | float | Latitude in degrees | about 25.8 to 47.5 |
| longitude | float | Longitude in degrees | about -122.4 to -71.0 |
| congestion_factor | float | Relative airport congestion (1.0 = average); raises delay risk of departures | 0.85 to 1.40 |

## carriers.csv (6 rows)
One row per carrier. Carrier names are fictional.

| Column | Type | Meaning | Value range |
|---|---|---|---|
| carrier_code | string | Two-letter carrier code (primary key) | NA, SJ, PW, EC, RL, AV |
| carrier_name | string | Fictional carrier name | 6 unique names |
| carrier_type | string | Business model | legacy, low-cost, regional |

## flights.csv (5,000 rows)
One row per flight (no cancellations or diversions are modelled).

| Column | Type | Meaning | Value range |
|---|---|---|---|
| flight_id | string | Unique flight identifier (primary key), ordered by date | F00001 to F05000 |
| flight_date | string (date, YYYY-MM-DD) | Scheduled date of the flight | 2025-01-01 to 2025-12-31 |
| month | int | Month number of `flight_date` | 1 to 12 |
| day_of_week | string | Weekday name of `flight_date` | Monday to Sunday |
| carrier_code | string | Operating carrier (foreign key to carriers) | 6 codes |
| origin | string | Departure airport (foreign key to airports) | 12 codes |
| destination | string | Arrival airport (foreign key to airports); never equal to `origin` | 12 codes |
| scheduled_dep_hour | int | Scheduled departure hour (local, 24h) | 5 to 22 |
| distance_miles | int | Great-circle distance between origin and destination, computed from airport coordinates | positive integer, determined by the airport pair (roughly 190 to 2,750) |
| weather_severity | float | Weather severity index at origin (0 = calm, 10 = extreme); higher in winter | 0.0 to 10.0 |
| dep_delay_min | int | Departure delay in minutes (negative = departed early) | -15 to 300 |
| arr_delay_min | int | Arrival delay in minutes (negative = arrived early) | -30 to 320 |
| is_delayed | int | Target flag: 1 if `arr_delay_min` >= 15, otherwise 0 | 0 or 1 |
