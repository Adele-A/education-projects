# Data description

All data is **synthetic**, generated by `src/data_generator.py` (numpy, seed 42). The simulated period is 2023-01-01 to 2024-12-31. Files are written to `data/`.

## customers.csv
One row per customer: 700 rows.

| Column | Type | Meaning | Value range |
|---|---|---|---|
| customer_id | int | Unique customer identifier | 1 to 700 |
| signup_date | date (YYYY-MM-DD) | Date of the first subscription | 2023-01-01 to 2024-12-28 |
| country | string | Customer country | US, UK, DE, FR, CA, AU, IN, BR |
| acquisition_channel | string | Marketing channel that brought the customer | organic, paid_ads, referral, outbound_sales |
| company_size | string | Size segment of the customer company | small, medium, large |
| initial_plan | string | Plan at signup | Starter, Growth, Enterprise |

## subscription_events.csv
One row per revenue event. Every customer has exactly one `new` event, and at most one `churn` event, which is its last event.

| Column | Type | Meaning | Value range |
|---|---|---|---|
| event_id | int | Unique event identifier, ordered by date | 1 to number of rows |
| customer_id | int | Foreign key to `customers.customer_id` | 1 to 700 |
| event_date | date (YYYY-MM-DD) | Date of the event | 2023-01-01 to 2024-12-28 |
| event_type | string | Kind of revenue movement | new, expansion, contraction, churn |
| plan | string | Plan after the event (plan held before churn for `churn` events) | Starter, Growth, Enterprise |
| seats | int | Number of seats after the event (0 for `churn`) | 0 or more; 1 or more for non-churn events |
| mrr_before | float | Customer MRR before the event, USD | 0 or more; 0 for `new` events |
| mrr_after | float | Customer MRR after the event, USD | 0 or more; 0 for `churn` events |
| mrr_change | float | `mrr_after - mrr_before`, USD | positive for `new` and `expansion`; negative for `contraction` and `churn` |

MRR is computed as `seats * price per seat`, where the price per seat is 12 USD for Starter, 25 USD for Growth and 45 USD for Enterprise.
